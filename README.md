# Yasunami

All-in-one Discord bot by **MILOX**.

Admin moderation, music, temp voice, welcome, rules, and a local dashboard.

Repo: https://github.com/hrvthblzs24/Yasunami

## Commands

- `/ban` `/kick` `/mute` `/unmute` `/deaf` `/undeaf` `/msg`
- `/play` `/pause` `/next` `/previous` `/stop` `/queue`
- `/tempvc setup` `/welcome setup` `/rules post`

Music needs ffmpeg on PATH and `pip install -r requirements.txt`.
